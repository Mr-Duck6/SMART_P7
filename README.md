# Практична робота 7 - Обробка та аналіз IoT-даних в openHAB


## Запуск
Відкрити PowerShell у кореневій папці проєкту:

docker compose config
docker compose up -d --build
docker compose ps


Відкрити:
- OpenHAB: http://localhost:8080
- Sitemap: http://localhost:8080/basicui/app?sitemap=climate


## Що містить
1. Віртуальні датчики температури та вологості трьох кімнат.
2. Публікація MQTT кожні 5 секунд, retained messages.
3. Збереження числових Items через RRD4j при зміні та щохвилини.
4. Поточне середнє, мінімум і максимум температури трьох кімнат.
5. Середня температура кожної кімнати за останню годину через averageSince.
6. Детекція зміни температури понад 5C відносно попереднього значення того самого Item.
7. Sitemap з поточними значеннями, аналітикою, журналом аномалій та графіками.

## Тестова аномалія
Симулятор автоматично вводить демонстраційний стрибок +6.5C кожні 180 секунд. Через наступний цикл температура повертається близько до попереднього рівня. Тому детектор може зареєструвати як стрибок угору, так і повернення вниз обидві зміни перевищують поріг 5 C.
